      Embeds inside allowed sites

      When an allowed site embeds a blocked one (a video, a login box, an ad script), empty that frame in place. The page itself keeps loading — only the embed becomes a "blocked" marker.

      Search results

      When on, a search page shows only the sites on your allowed list. The query goes straight to the search engine and this extension stores nothing.

      Add the search engine itself (for example google.com) to Allowed Websites, or the results page cannot open.
