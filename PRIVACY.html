Privacy Policy — Family Website Monitor

Last updated: 2026-10-15

This policy covers the Chrome extension Family Website Monitor (the "extension"). It is written for the Chrome Web Store listing and for anyone installing it for their family.

Short version

The extension has no analytics, no tracking, no advertising, no accounts and no servers of its own. Every piece of data it uses is stored on the device it runs on. Nothing is uploaded anywhere by us.

What it stores, and where

DataWhere it livesLeaves the device?

About Chrome sync. The extension mirrors the rule configuration (whitelists, blocklists, schedule, limits, screen-time settings) through chrome.storage.sync so a family with two computers configures the lists once. That data goes to Google under the user's own Chrome sync account, on Google's terms — not to us. Passwords, PINs, sessions and all usage counters are explicitly excluded from sync and never leave the device.

What the extension does not do

  • It does not collect, transmit or sell personal information of any kind.
  • It has no telemetry, crash reporting, analytics SDKs or advertising.
  • It downloads no remote code. Everything it runs is inside the package.
  • It does not store search queries. The new-tab search opens the search engine's own results page directly, and the optional parent-enabled filter ("only allowed sites") hides non-allowed results on that page; the query never reaches the extension's storage.
  • It does not keep a browsing history anywhere except the local usage report on this device, which the parent can clear from the panel and which is pruned to the last 14 days automatically.
  • It cannot read pages on chrome://, the Chrome Web Store, or PDFs, and makes no attempt to.

The one request it makes by itself. Every six hours the extension fetches the published version.json of this project from this repository's public GitHub page, to light an "update available" badge on its toolbar icon. The request carries only a cache-busting timestamp — no identifiers, no settings, no usage data — and it is the extension's sole outbound request.

Children's privacy

No data is collected from anyone, including children. Because the extension collects nothing, no child's information is stored, processed or shared.

Data retention and deletion

  • The usage report keeps at most 14 days and is cleared by the parent from the panel at any time.
  • Uninstalling the extension removes everything: the background worker clears its local settings and purges the synced mirror on uninstall.
  • "Clear all data" from Chrome's extension page removes the rest.

Security

  • The parent password and PIN are stored only as PBKDF2-SHA256 hashes (310,000 iterations, random per-password salt, constant-time comparison). They are never readable in plaintext, never synced and never logged.
  • Five wrong attempts lock the panel for a cooldown period.
  • The panel locks itself automatically when its tab is hidden.
